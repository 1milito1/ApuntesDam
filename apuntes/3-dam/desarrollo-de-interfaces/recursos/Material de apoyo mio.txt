1. COMPONENTE PERSONALIZADO (EL BEAN)
Archivo: TextFieldBean.java


Objetivo: Crear un campo que detecte una "Palabra Secreta" configurada desde las propiedades.

Java
package componentes;

import javax.swing.JTextField;
import java.awt.event.KeyAdapter;
import java.awt.event.KeyEvent;
import java.io.Serializable;

public class TextFieldBean extends JTextField implements Serializable {
    
    // Propiedad pedida (1 punto) [cite: 18]
    private String palabraSecreta = "";

    public TextFieldBean() {
        super();
        // Redefinir KeyReleased (2 puntos) [cite: 19]
        this.addKeyListener(new KeyAdapter() {
            @Override
            public void keyReleased(KeyEvent e) {
                comprobarPalabra();
            }
        });
    }

    // Getters y Setters necesarios para ser Bean [cite: 18]
    public String getPalabraSecreta() { return palabraSecreta; }
    public void setPalabraSecreta(String palabraSecreta) { this.palabraSecreta = palabraSecreta; }

    private void comprobarPalabra() {
        String textoActual = this.getText();
        if (palabraSecreta != null && !palabraSecreta.isEmpty() && textoActual.equals(palabraSecreta)) {
            this.setText("prohibido escribir esta palabra"); // [cite: 19, 21]
        }
    }
}

5. INTERACCIÓN DINÁMICA CON EL MOUSE

Objetivo: Cambiar el estado visual (colores, imágenes o texto) cuando el usuario interactúa físicamente con el componente.

A. Cambiar Imagen/Icono al hacer clic
Ideal para componentes que deben reaccionar visualmente para dar retroalimentación.

Java
// Dentro del constructor del Bean o en el initComponents del Frame:
objeto.addMouseListener(new java.awt.event.MouseAdapter() {
    @Override
    public void mouseClicked(java.awt.event.MouseEvent evt) {
        // Cambiar el icono de un JLabel al hacer clic
        jLabelFoto.setIcon(new javax.swing.ImageIcon(getClass().getResource("/ruta/imagen2.png")));
    }
    
    @Override
    public void mouseEntered(java.awt.event.MouseEvent evt) {
        // Efecto visual al pasar por encima (Mejora de Usabilidad)
        objeto.setBackground(java.awt.Color.YELLOW);
    }

    @Override
    public void mouseExited(java.awt.event.MouseEvent evt) {
        // Volver al estado original al salir
        objeto.setBackground(java.awt.Color.WHITE);
    }
});

6. Lógica de Arrastre en el Bean (InteractiveLabelBean)
Java
public class InteractiveLabelBean extends JLabel implements Serializable {
    private String textoAlerta = "ALERTA";

    public InteractiveLabelBean() {
        this.setText("Estado Normal");
        
        // Listener interno para autonomía del Bean (Unidad 2)
        this.addMouseMotionListener(new java.awt.event.MouseMotionAdapter() {
            @Override
            public void mouseDragged(java.awt.event.MouseEvent evt) {
                // Si el ratón se mueve a la derecha (X > 20px)
                if (evt.getX() > 20) {
                    setForeground(java.awt.Color.RED); // Cambio de aspecto (Unidad 3)
                    setText(textoAlerta);
                }
            }
        });

        this.addMouseListener(new java.awt.event.MouseAdapter() {
            @Override
            public void mouseReleased(java.awt.event.MouseEvent evt) {
                // Restaurar al soltar el clic (Retroalimentación visual)
                setForeground(java.awt.Color.BLACK);
                setText("Estado Normal");
            }
        });
    }

    // Getters y Setters para Introspección (Unidad 2)
    public String getTextoAlerta() { return textoAlerta; }
    public void setTextoAlerta(String t) { this.textoAlerta = t; }
}
